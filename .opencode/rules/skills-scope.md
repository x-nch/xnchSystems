# Skill Scope (xnchSystems)

This repo is a systems/control-plane engineering project (FastAPI execution
engine + control-plane API). The only skills in scope here are the
engineering set under `.opencode/skills/`:

- superpowers engineering skills (systematic-debugging, test-driven-development,
  writing-plans, using-git-worktrees, requesting/receiving-code-review,
  verification-before-completion)
- `code-review-graph` (this repo's review MCP)
- `review-loop` (review->fix->verify)

## Out of scope (do NOT invoke)
Marketing / growth / SEO skills loaded globally from `~/.agents/skills` and
`~/.claude/skills` (e.g. ad-creative, seo-audit, cold-email, influencer-marketing,
pricing, landing-page, video, social). These are for other projects on this
machine and must not fire for xnchSystems work. If a request looks marketing-shaped,
flag it rather than loading those skills.
