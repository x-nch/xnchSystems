````markdown
# Reddit special-agent routing (2026-09-07)

The Mac dispatch runner (`agent-runner/xnch_agent_runner/runner.py`) routes any
claimed run whose prompt starts with `@reddit` to the trusted Reddit executor
(`scripts/reddit/reddit_agent.py`) instead of spawning opencode. The sandboxed
LLM never sees Reddit credentials and cannot reach the network — the single
external call lives in this runner hook.

## Trigger

```text
@reddit {"task": "…"}   # valid JSON after the @reddit prefix
```

## Credentials

- Env: `XNCH_REDDIT_CLIENT_ID` + `XNCH_REDDIT_PASSWORD`, or `~/.xnch/reddit.env`.
- No creds present ⇒ `--dry-run` (no network). Real creds belong only in
  node/mac env files, never the repo (`scripts/reddit/reddit.env.example`).

## Outcome

Reports `POST /agents/runs/{run_id}/outcome` with `DONE|FAILED`, `exit_code`,
and `result_text` (last 20000 chars) or `error` (last 2000). Failed runs and
invalid `@reddit` JSON both land as `FAILED`, never crash the runner loop.
````
